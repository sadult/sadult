<summary><b>🕊️ &nbsp;HOMA — Hands-On Machine Assistant</b></summary>
<br/>

> **«خلبانِ خودکارِ مرورگر و سیستمِ تو»** — an agent you command from your phone.

Send a plain sentence from Telegram — *"check how much space drive C has"*, *"open this form and fill it"*, *"did Ali email me?"* — and HOMA plans the steps, drives a real Chromium session, executes system tools, and streams a readable Persian log back to you.

**Highlights**
- ReAct agent loop with JSON-schema tool registry
- Persistent Playwright session (keeps you logged in between commands)
- Telegram bot + FastAPI web UI with live WebSocket logs
- Security guard: allow-list, blocked shell patterns, human confirmation for dangerous calls

`Python` `Playwright` `FastAPI` `WebSocket` `python-telegram-bot` `OpenAI SDK`

</details>

<details>
<summary><b>🐔 &nbsp;morghie (ربات مرغی) — Telegram economy game</b></summary>
<br/>

A multiplayer economy game living inside Telegram groups: raise chickens, collect eggs, upgrade coops, earn offline income, bank at 5% daily interest, raid your friends. Currently at **v2.0** with a full player handbook.

**Highlights**
- Group-native gameplay loop with keyword triggers
- Offline income engine + banking & shop systems
- Anti-abuse and rate-limiting layer

`Python` `Telegram Bot API` `SQLite` `Game economy design`

</details>
